# 📅 Agenda Virtual

Sistema web para comunicação entre escolas e responsáveis, desenvolvido como projeto pessoal para estudo e aplicação de boas práticas de desenvolvimento.

## 🚧 Status

Em desenvolvimento.

Atualmente o projeto encontra-se na fase de planejamento da arquitetura (System Design).

## 🎯 Objetivo

Desenvolver uma aplicação completa utilizando Java, Spring Boot e Angular, com foco em uma arquitetura organizada, escalável e alinhada às práticas utilizadas no mercado.

## 🛠️ Tecnologias previstas

- Java
- Spring Boot
- Spring Security
- JWT
- PostgreSQL
- Flyway
- Angular
- TypeScript
- Docker
- Swagger
